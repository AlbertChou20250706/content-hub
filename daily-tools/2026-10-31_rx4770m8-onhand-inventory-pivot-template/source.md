樞紐範本是一份針對 RX4770M8 伺服器料件庫存管理設計的 Excel 樞紐分析範本：把 WMS 匯出的在手庫存（Onhand Query）原始資料，透過 Excel 內建的樞紐分析表（Pivot Table）轉成可直接判讀的彙總視圖，同時搭配一張報廢清單（Scrap list）追蹤已報廢料件，不含任何程式碼，純粹是一份「資料結構 + 分析手法」的範本。

## 為什麼值得關注

伺服器料件庫存與報廢追蹤是維運現場天天要碰的工作，但很多團隊的做法還停留在「每天打開一份原始清單，人工用篩選、複製貼上去對帳」，資料量一大就很容易漏算或對錯行。這份範本沒有寫一行程式，而是示範怎麼用 Excel 最基礎但最容易被低估的功能——樞紐分析表——把雜亂的原始庫存資料變成固定格式的彙總報表，資料更新後重新整理樞紐表即可，不需要重新設計報表版面。它也和同一批素材裡另一支工具 `CallbackTool`（WMS CSV 自動驗證工具）形成有意思的對照：同樣是從 WMS 匯出 Onhand Query 起手，一邊走向全自動化的 Power Query 比對流程，一邊停留在最輕量的人工樞紐分析——同一個資料來源，兩種複雜度完全不同的解法。

## 內容結構

實際下載並讀過 README 與 `RX4770M8_Onhand Query_0121.xlsx` 之後，整份範本只有三張工作表，分工很清楚：

- **`onhand-query`**：伺服器料件現有庫存的原始資料表，對應 WMS 系統匯出的格式，是整份範本的唯一資料來源。
- **`樞紐`**：基於 `onhand-query` 建立的樞紐分析表，把原始明細彙總成可直接判讀的統計視圖，不需要額外公式或巢狀 VLOOKUP。
- **`Scrap list`**：料件報廢紀錄表，與在手庫存分開維護，方便單獨追蹤已報廢但仍需留存記錄的料件。

README 本身也明確標註了這份資料的性質：「純文件（試算表範本），無程式碼，不是可執行的工具，也不是 SOP」——這個自我定位很清楚地劃出了它和同系列其他自動化腳本的邊界。

## 可延伸應用角度

適合用來做一支「從手動到自動化」主題的對比短片：先用這份樞紐範本示範最基礎、幾乎零成本就能上手的庫存分析做法，再銜接到 `CallbackTool`（WMS CSV 自動驗證工具）展示同一份 Onhand Query 資料如何被 Power Query 接手做自動比對與異常統計，呈現同一個現場痛點在不同投入程度下的兩種解法，也能順勢帶出「什麼時候該從 Excel 樞紐升級到自動化工具」的判斷標準。
