# SIT 數位武裝模組（V16 雙向同步版）：把結構化思考框架變成可複製貼上的溝通稿

一支單檔 HTML 工具，把「GPS 測試路徑規劃」「5W2H 異常回報」「RCA 問題金三角」這類 SIT／工程常用的結構化思考框架，變成可以直接填寫、一鍵複製、匯出成 Markdown／CSV／JSON 的表單系統，專門解決「腦中有框架、但講出來／寫出來卻語無倫次」的落差。

## 這是什麼

`sit_framework_v16.html` 是一個不需要任何後端、伺服器或安裝的單一 HTML 檔案，開啟即可在瀏覽器裡使用。畫面預設載入三組 SIT／測試工程師常用的結構化框架：

- **GPS 測試路徑規劃**：Goal（目標）／Position（現狀）／Steps（步驟分流）
- **5W2H 異常回報（HUD）**：What／When／Who／Whom／Where／How／How impact，對應到 bug 回報時常被主管追問卻答不出來的欄位
- **RCA 問題金三角**：現象（Problem）／真因（Root Cause）／對策（Countermeasure）

每個框架都是一張可編輯卡片，欄位可以自由新增／刪除，框架本身也能新增／刪除，等於是一個「自訂結構化報告產生器」而不是死板模板。

搭配的 `會議簡報Email當下會怎麼講怎麼寫.md` 則是這套框架的「口語翻譯範例」：示範同一套「結論先行」「MECE 拆解」「SCQA」邏輯，在會議上被主管打斷時該怎麼接話、簡報五頁怎麼排、跨部門 email 怎麼下標題與收尾，把抽象框架轉成逐字稿等級的示範句。

## 為什麼值得關注

SIT／測試工程師最常見的痛點不是「不會分析問題」，而是「分析完了，會議上講不清楚、簡報排不出重點、email 寫了老半天主管抓不到結論」。這份工具刻意把「腦中模組」跟「嘴巴說出來的話」分開標註（md 檔逐句示範），讓使用者能直接照樣造句，而不是再學一套溝通理論。這跟一般的簡報範本或溝通課程講義不同之處在於：它是一個活的、可持續擴充的表單工具，不是一次性的靜態文件。

## 技術重點（實際讀過原始碼）

這支 HTML 完全依賴原生 JavaScript（無框架、無外部套件），但功能密度不低：

- **雙語即時切換**：所有框架標題／欄位標籤都以 `{zh, en}` 物件儲存，`toggleLang()` 搭配 `withStatePreservation()` 在切換語言時保留使用者已填寫的內容不遺失。
- **動態表單 CRUD**：`addModule()` / `deleteModule()` / `addField()` / `deleteField()` 讓使用者用 `prompt()` 直接新增自訂框架與欄位，不需要碰程式碼。
- **一鍵複製與多格式匯出**：`copyModuleText()` 複製單一區塊、`copyAllText()` 複製全部內容到剪貼簿；`exportData()` 支援匯出成 JSON（含 schema + data，可原樣匯入回填）、Markdown（`# SIT Report` 結構）、CSV（含 BOM 避免中文亂碼）。
- **最特別的「貼上並同步架構」（V16 核心賣點）**：`applyPastedText()` 實作了一個簡易的雙向工程解析器——使用者把「【模組名稱】」＋「欄位：內容」格式的文字貼回去，系統會用 regex（`^【(.*?)】` 抓模組、`^([^：:]{1,60})[：:](.*)$` 抓欄位）反向重建整個表單結構，並嘗試比對舊有的 schema 保留雙語標籤，找不到對應的欄位還會用括號或方括號啟發式規則（如 `重製 (Rebuild)` 或 `[Why]`）自動拆解出英文標籤。這代表使用者可以把表單內容丟給 AI 助手潤飾/改寫成文字，再貼回網頁自動重建結構，形成一個「表單 ↔ 純文字」互相轉換的迴圈。
- **無資料庫、無後端**：所有狀態都在記憶體中（`frameworkConfig` 陣列），重新整理頁面即重置，設計上刻意搭配 JSON 匯出/匯入做持久化，是典型的「零依賴單檔工具」設計哲學。

## 可延伸應用角度

- 適合做成「工程師溝通力」系列影片的示範素材：直接錄製「填表單 → 複製 → 貼進 email/簡報」的實際操作流程，比單純講解理論更有說服力。
- 可以跟先前收錄的「OT Calculator」「RAID CC 驗證工具」等單檔 HTML／腳本工具放在同一個「零依賴工具」系列裡做橫向比較，凸顯 Albert 一貫的極簡工具設計風格（單檔、無安裝、匯出格式多元）。
- 「貼上並同步架構」這個逆向解析功能本身就是一個值得單獨拆解的技術主題：如何用簡單的 regex heuristic 做「文字 → 結構化資料」的雙向轉換，可以延伸成一支「不用 AI 也能做結構化解析」的技術短片。
