IPMI_code_for_Fan_code 是一份透過 `ipmitool` 直接對伺服器 BMC 下 raw command、讀寫風扇代碼（Fan code）的指令備忘單，記錄了設定與檢查 Fan code 所需的完整 raw 指令與遠端呼叫語法。README 開頭就老實標注「類型：SOP（操作步驟、指令備忘筆記），無程式碼，不是可執行的工具」——這份候選跟過去介紹過的工具腳本不同，是一份值得單獨拿出來講的「指令級知識」素材。

## 為什麼值得關注

伺服器風扇轉速異常、產線要固定轉速做噪音/散熱測試、或是 BMC 自動調速邏輯需要暫時覆寫時，工程師常常需要手動對 BMC 下 raw command 來讀寫 Fan code，但這類指令幾乎都是廠商技術文件裡才找得到的位元組序列，網路上公開資料很少，容易每次要用都要重新試錯或問前輩。這份筆記把「怎麼設」「怎麼查」兩種操作都備齊，而且附上實際執行畫面截圖佐證指令可行，是那種平時不起眼、真的要用時卻很難快速找到的知識資產。

## 技術重點

實際下載並讀過 `IPMI_code_for_Fan_code.txt` 全文後：

- **設定 Fan code 的三行 raw command**都是同一個指令前綴 `ipmitool raw 0x2e 0x09 0xfd 0x19 0x0 0xC`，差別只在倒數第二個 byte（`0xC6`／`0xCC`／`0xC8`），對應三組不同的風扇代碼設定值——代碼本身的具體語意沒有寫在筆記裡，使用時仍需對照廠商 Fan code 表，這份筆記記的是「怎麼下指令」而非「代碼對照表」。
- **遠端下指令的語法**額外示範了 `ipmitool -I lanplus -H <IP> -U <帳號> -P <密碼> raw ...`，也就是透過 lanplus 介面對遠端 BMC（而非本機 in-band）下同一組 raw command，這在量產線上對多台機器批次設定時是常用路徑。
- **檢查目前 Fan code 的指令**是另一組 raw command（`0x2e 0x0e 0xfd 0x19 0x00 0x01`），跟設定指令的 sub-command byte（`0x09` vs `0x0e`）不同，是一組獨立的「讀」指令，可以在設定前後各查一次做驗證。
- 檔案開頭附了一條 Claude 對話分享連結，推測是作者整理這份筆記時藉助 AI 協助確認過指令語法，但沒有進一步展開說明背景，實際指令是否通用於所有機型仍需使用者自行確認。

## 可延伸應用角度

- 適合做成「BMC raw command 怎麼查、怎麼用」的短篇知識型影片，用這份筆記當具體案例，講解 IPMI raw command 的結構（NetFn/CMD/OEM bytes）跟去哪裡查廠商規格書，比單純介紹一支工具更能幫助聽眾舉一反三。
- 可以跟先前介紹過的 `get_bmc_bios_info`（BMC/BIOS Redfish 資訊比對工具）、`OOB_Check`（IPMI 組合檢測工具）串成「BMC/IPMI 操作實戰系列」，呈現同一類 BMC 管理介面在不同場景（資訊讀取、硬體檢測、風扇控制）各自怎麼下手。
- 這份素材本身篇幅短，單獨做內容可能偏薄，比較適合作為系列節目裡的「指令小抄」單元，而不是獨立一支長影片的主題。
