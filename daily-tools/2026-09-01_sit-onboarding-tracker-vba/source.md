# SIT 新人訓練樣板 — 用一支 Excel VBA 巨集，把「改狀態就自動補日期」做成流程自動化

## 這是什麼

一份給 SIT 部門用的新人訓練追蹤 Excel 樣板（`.xlsm`），核心不是表格本身，而是綁在「清單_Template」工作表上的一段 VBA：訓練項目的「狀態」欄一改，開始日期／完成日期就自動填上或清空，把「訓練 → 教學 → 測試驗證 → 評語 → 結果 → 存檔」六階段流程，變成不用手動記日期的狀態機。

## 為什麼值得關注

新人訓練追蹤這件事，多數團隊的做法是一張純手填的 Excel 清單：誰在教、教到哪、哪天開始哪天結束，全部靠人工補登，時間一長就會有漏填、日期對不上的問題。這份樣板的做法值得注意的地方，在於作者沒有選擇「換一套系統」（例如上 Jira / Notion），而是在既有的、每個人都會用的 Excel 裡面，用一段不到 60 行的 VBA 把「狀態驅動」的自動化邏輯內建進去——這跟同一位設計者其他幾支工具（`驗證WMI` 的硬體健檢報告、`工程團隊級測試進度管理系統模組等級` 的 RX4770M8 TSR 進度看板）背後是同一套「改狀態、其他欄位跟著自動更新」的設計哲學，只是這次載體從 Web Dashboard 換成最貼近現場使用者習慣的 Excel。對於想在不引入新系統、不需要 IT 導入成本的前提下做內部流程自動化的人，這是一個具體可抄的最小可行方案。

## 技術重點（實際看過下載下來的內容）

- **狀態驅動日期的核心是 `Worksheet_Change` 事件，只監控「狀態」這一欄**：VBA 一開始就用 `If Intersect(Target, Me.Columns(5)) Is Nothing Then Exit Sub` 把觸發範圍鎖死在 E 欄（狀態），並用 `If Target.CountLarge > 1 Then Exit Sub` 擋掉貼上多格造成的批次觸發，避免使用者複製貼上整欄資料時炸出一堆非預期的日期填寫。
- **用 `Application.EnableEvents = False/True` 包住整段邏輯，防止修改儲存格觸發自己**：因為這段程式本身也會寫回 G 欄（開始日期）、H 欄（完成日期），如果不關掉事件監聽，寫入動作會遞迴觸發同一個 `Worksheet_Change`。這是 Excel VBA 裡處理「監聽變更又要改自己」的標準防遞迴寫法，搭配 `On Error GoTo CleanUp` 確保就算中途出錯，事件監聽也一定會被恢復開啟，不會把整張工作表的自動化鎖死。
- **四種狀態轉換各對應不同的清空/填寫規則**：狀態非空白 → 只在「開始日期」原本是空的時候才填入今天（不覆蓋已有值）；狀態改成 `pass` 或 `N/A` → 補「完成日期」；狀態改成 `clear` → 開始日期、完成日期、狀態本身三個一起清空，等於一鍵重置這一列；狀態被清空 → 只清兩個日期、保留其他欄位。這個「clear 會連狀態自己都清掉」的設計，跟前三種只清日期的邏輯不對稱，是刻意讓使用者有一個「整列歸零重跑」的顯式入口，而不是要手動一格一格刪。
- **下拉選單走的是具名範圍，不是硬寫在資料驗證裡的字串清單**：責任人（`MemberList`）跟狀態（`StatusList`）都先在「參數設定」工作表的 E/F 欄建立清單，再用【公式】→【定義名稱】註冊成活頁簿範圍的具名範圍，資料驗證的來源直接引用 `=MemberList`／`=StatusList`。README 裡專門有一段「常見問題」在講如果直接把清單文字用分號接在資料驗證來源欄，Excel 不會自動拆開——這是資料驗證用「參照儲存格」失敗、改成「參照具名範圍」的具體踩坑記錄，對用 Excel 做內部工具的人是很實用的細節。
- **活頁簿裡實際打包了 `xl/vbaProject.bin`（約 53KB）**，用 `unzip -l` 攤開 `.xlsm` 內部結構可以看到 7 個對外可見工作表（封面／版本與進版資訊／功能說明／參數設定／使用流程／清單_Template／報表），加上 `xl/tables/table1.xml` 把「清單_Template」的主表格範圍設成 Excel 表格物件——不是單純的儲存格區塊，這樣後續要用結構化參照（Structured Reference）或轉 Power Query 都比較好接。
- **`Previous/` 底下還留了 v1.0.0、20260119 兩個舊版存檔**，跟這系列其他工具（`驗證WMI`、`SUSE15SPX` 的 SUT Toolkit）一樣，是同一位作者一貫的「改版前先另存一份」的個人版本控制習慣，沒有用 Git，但保留了可追溯的檔案級歷史。

## 可延伸應用角度

- **「不換系統、在 Excel 裡塞一段 VBA 做狀態機」這個切角**很適合獨立做一支「輕量流程自動化」短片，用這裡完整的 `Worksheet_Change` 程式碼當教學範例，講清楚防遞迴（`EnableEvents`）跟鎖定監控範圍（`Intersect`）這兩個任何人寫類似巨集都會用到的基本功。
- **可以跟已介紹過的 `驗證WMI`（2026-08-28）、`RX4770M8 TSR 測試進度看板`（2026-08-30）**一起做成一集「同一位設計者、三種載體，同一套『改狀態→其他欄位自動跟著動』設計哲學」——從 Excel VBA、到 PowerShell 報告產生器、到 Web Dashboard，講清楚同一個自動化思維在不同技術限制下會長成什麼樣子。
- **資料驗證「參照儲存格 vs 參照具名範圍」這個踩坑細節**，也適合單獨做成一支「Excel 內部工具設計常見錯誤」的短片，因為這是幾乎每個第一次用下拉選單做內部表單的人都會踩到的坑。
