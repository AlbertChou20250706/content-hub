OT Calculator — Albert Style 是一個完全離線的單一 HTML 加班時數試算工具，搭配 PowerShell 啟動器，把「上下班打卡時間」自動換算成淨工時、加班分鐘數，以及可以拿去跟 HR 申請的加班小時數。

## 為什麼值得關注

加班時數試算是製造業／SIT 測試團隊裡幾乎每個人都手動算過的痛點：午休要不要扣、晚餐後才開始起算 OT、公司的申請門檻與進位規則（捨去到 1 小時？四捨五入到 0.5 小時？）常常因公司而異，用 Excel 手算很容易出錯或每次都要重建公式。這個工具把這些規則寫死成參數化邏輯，輸入打卡時間就能一次算完，而且完全在瀏覽器端運算、不用連網、不會外流任何出勤資料。

從資料夾裡的版本演進（v1.0 → v1.1.1 → v1.3.0）也能看到這是一個持續被真實使用、真實迭代的個人工具，而不是寫完就沒再動過的一次性腳本。

## 技術重點

實際下載並讀過資料夾內容後，重點如下：

- **核心規則邏輯**：標準工時預設 8 小時；若 8 小時區間跨到 12:00–13:00 午休，標準下班時間會順延 1 小時（`standardEnd()`）。加班（OT）從「標準下班時間 + 晚餐時間（預設 0.5h）」之後才開始計算，避免把吃飯時間也算進加班。
- **可申請時數（Claim）規則**：加班分鐘數要先過最低門檻（預設 1 小時）才會被採計，通過門檻後再依四種進位規則之一換算：捨去到 1h、四捨五入到 1h、進位到 1h、或四捨五入到 0.5h（`roundClaimMins()`）。
- **版本落差是個有趣的真實案例**：資料夾根目錄的 `OT_Calculator.html`（掛在 `.bat`/`.ps1` 啟動器上、實際會被使用者打開的版本）還停在 v1.1.1；但 `OT_Calculator/` 子資料夾裡已經有寫好的 v1.3.0，多了三語系（中文／英文／日文）UI 切換、週一到週六的週彙總看板（每日 OT 分布）、CSV 匯出，以及六組配色主題。也就是說新功能已經做好了，但還沒同步回「正式上線」的檔案——這是個人工具迭代中很典型的「功能領先、部署落後」場景。
- **v1.1.1 README 裡記了一個防抖動的除錯開關**：`const GUARD = false` 搭配 `smallDrift`／`hugeJump` 判斷，是用來避免重複觸發計算時畫面閃爍或吃到過期資料的防護邏輯，README 也直接寫了「如果按 Calculate 沒反應要去確認這個開關」——顯示這是實際被使用者回報過問題、進而修的。
- **啟動器設計**：`OT_Calc_Launcher.ps1` 會偵測本機 Edge 瀏覽器路徑，用 `--app=` 參數以「類原生 App」模式（無網址列/分頁）開啟 HTML，找不到 Edge 才退回系統預設瀏覽器——用純前端 HTML 做出接近桌面應用的使用體驗，不需要打包 Electron 或安裝任何執行環境。
- 全程無後端、無依賴套件，純 vanilla JS + inline CSS 寫在單一 HTML 檔裡，複製這一個檔案就能在任何一台裝有瀏覽器的電腦上跑。

## 可延伸應用角度

- 適合做成「個人生產力工具 / vibe coding」系列影片：示範如何用 AI 輔助，把一支單一 HTML 檔案的小工具從 v1.0 一路加到 v1.3（i18n、週彙總、CSV 匯出、主題切換），拿版本間的 diff 當作「功能怎麼一步步長出來」的案例教學。
- 也適合搭配「職場工時 / 加班眉角」類內容，講解台灣職場常見的加班認定規則（午休扣除、晚餐後才起算、最低申請門檻與進位方式），用這個工具的規則設計當範例。
- 可以延伸討論「單一 HTML 檔工具」這個形式本身的優點：離線可用、無需安裝、方便用隨身碟或內部共享資料夾分發，特別適合企業內網無法安裝額外軟體的環境。
