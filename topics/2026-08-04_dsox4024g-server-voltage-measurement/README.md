## 背景

新手工程師、QA 測試員與產線人員第一次面對 DSOX4024G 示波器時，常被面板上密集的旋鈕、按鈕跟原廠厚重的技術手冊嚇退。但實際上，日常伺服器電壓量測工作只需要用到手冊裡的一小部分功能——把 90% 以上的日常需求濃縮成接線、介面設定、存檔三個核心動作即可涵蓋。E1 硬體團隊已在主機板上預先拉出標準化測試點（3.3V、12V、CPU 12V），操作者不需要再拿探棒在密集的 SMD 元件或 IC 腳位上盲測。

## 做了什麼

1. 實體接線：固定通道對應——CH1 = 主機板 3.3V，CH2 = 主機板 12V，CH3 = CPU 電源 12V。通電前務必先確認接地夾咬住主機板接地點才能插上 AC 電源，順序顛倒輕則量到雜訊浮動電壓，重則燒毀待測物或示波器。若待測卡功耗低、沒有外接 GPU 電源設計，CH3 直接略過，不需要湊齊三通道卡住流程。
2. 介面設定：開機等待 READY 畫面，手動開啟 CH2、CH3（系統預設只開 CH1）。區分兩個容易混淆的按鈕：接手別人剛用過的機器時按「Default Setup」清除殘留設定；正式測試（例如跑 NVQual 這類測試腳本）前按「Clear Display」，只清畫面殘留波形、不動設定。
3. 快速存檔（五步驟）：按 Save → 選 PNG 24-bit（避免壓縮糊掉波形細節）→ 確認存檔路徑指向隨身碟 → 檔名包含裝置名稱與日期 → 按下存檔並確認成功提示。效率補充：把調好的 Timebase、Voltage Scale 等參數另存為 Setup 設定檔，量產測試多台同型號硬體時一鍵載入。

## 關鍵發現／重點

- 日常量測 90% 以上的需求只需要接線、設定、存檔三個核心動作，不需要啃完整本手冊
- 固定通道對應規則讓不同工程師產出的截圖顏色一致，review 時不用互相確認「這條線是哪個電壓」
- 接地永遠在通電之前，這條安全規則沒有例外
- 標準流程要保留彈性：硬體用不到的通道就跳過，不要被死板的 SOP 卡住
- 效率的核心不是掌握進階冷門功能，而是把流程標準化到任何人都能照著做不出錯
