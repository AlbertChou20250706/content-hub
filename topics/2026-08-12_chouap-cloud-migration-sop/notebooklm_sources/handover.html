ChouAP.Cloud

專案雲端化交接手冊

把本機（或雲端硬碟同步路徑下）的專案，搬成「GitHub repo + Claude Code Cloud environment」的雲端工作流。搬完後任何裝置登入同帳號都能接續，不再依賴單一台電腦開機。

✓ 以 audio_transcribe 專案實際驗證可行

設計者 / Designer：Albert Chou ・ 文件版本 v1.0.0

A搬完長什麼樣 — 架構與資料流

GitHub repo 是中樞（單一事實來源），往下給雲端、往左給本機桌面；任何裝置登入同帳號都能接續。

B先搞懂四個核心觀念

這四點先弄清楚，實際搬的時候才不會卡住。

GitHub repo = 單一事實來源

Cloud session 在雲端一台獨立乾淨的 Ubuntu 主機跑，透過 GitHub clone 你的程式碼進去，不是直接讀你電腦的資料夾。所以程式碼一定要先在 GitHub 上。

environment ≠ repo

兩者常同名容易混淆：environment 是「執行環境」（要裝什麼工具），repo 是「程式碼本身」。開 session 時兩個都要選。

雲端內建工具有限

Python、Node、Go、Rust、Java、Ruby、PHP、Docker 已預裝；但 PowerShell、.NET SDK 等不在清單，要靠 Setup script 自己裝。

Setup script 只跑一次會快照

只在「開全新 session」時跑，第一次跑完存成快照，之後開新 session 直接沿用不重裝。改了內容或約七天後快照失效重建。Resume 不會重跑。

C怎麼搬過去 — 八個步驟

照順序做即可，每步都在 audio_transcribe 上實際走過。

  1. 複製到非雲端同步路徑雲端硬碟路徑下的專案先複製（不要剪下）到 C:\Projects\<專案名>。Git 資料庫跟 Google Drive 放一起容易互相干擾。
  2. 準備三個骨架檔案.gitignore（排除大檔）、README.md（專案說明）、CLAUDE.md（規範＋現況，session 會自動讀取）。
  3. 初始化 Git 並 commitgit init → git add . → git commit -m "Initial commit"。別漏 git add .。
  4. 在 GitHub 建空的 Private repo名稱填 <專案名>、選 Private、不要勾 Add a README。
  5. 推上 GitHubgit remote add origin ... → git branch -M main → git push -u origin main。
  6. 授權 Claude GitHub App 存取 repo選 repo 時若出現「Repo missing」，點 Install the Claude GitHub app，選 Only select repositories 只勾這個 repo。
  7. 建立 Cloud environmentName 填專案名、Network 維持 Trusted、變數留空、Setup script 依語言填（PowerShell 專案要裝 pwsh）。
  8. 開 session 並驗證第一句先驗證環境（如 pwsh --version）再進正題。若回報「未安裝」代表 Setup script 有問題。

D兩個實戰雷點（務必避開）

這兩個是 audio_transcribe 搬遷時真的踩到的坑，寫下來給後面的人。

雷點 1 — commit 前漏了 git add

只跑 git commit 不跑 git add .，會出現 nothing added to commit but untracked files present。git add . 是把檔案加進 staging area，一定要先做。（LF will be replaced by CRLF 只是換行提示，不是錯誤，忽略即可。）

雷點 2 — Setup script 別用 && 串一長串

用 && 串起來時，只要 apt update 因為任何無關的 PPA 回應 403，整條鏈就會斷掉，後面的安裝根本不執行，卻又被 || echo 吞掉、exit 0 讓系統誤以為成功。正確做法是每步拆開、apt update 後單獨接 || true：

# ✗ 錯：一步斷掉全斷
wget ... && dpkg -i ... && apt update && apt install -y powershell || echo "..."

# ✓ 對：每步獨立成行
#!/bin/bash
wget -q https://packages.microsoft.com/config/ubuntu/24.04/packages-microsoft-prod.deb -O /tmp/packages-microsoft-prod.deb
dpkg -i /tmp/packages-microsoft-prod.deb
apt update || true
apt install -y powershell || echo "PowerShell install failed, check manually"
exit 0
