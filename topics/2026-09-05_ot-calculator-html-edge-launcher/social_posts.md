## Threads / X（短，≤ 280 字，含 1 個 hook）

加班費用 Excel 手算到懷疑人生？我把公司那套千奇百怪的規則（午休扣除、晚餐起算、進位方式）全部參數化，做成一個單檔 HTML 工具，離線就能用——而且不用 Electron，靠 Edge 的 `--app=` 參數就有原生桌面體驗。現在也上架 Microsoft Store 了。

## LinkedIn（技術向，可長一點，強調專業紀錄）

製造業與 SIT 團隊的加班時數計算，規則常常公司之間差很多：午休扣不扣、晚餐後幾點起算、進位捨去還是四捨五入到 0.5h。與其每次手動核對規則，我把整套邏輯寫成單檔、離線可用的 HTML 小工具 OT Calculator，搭配 Edge 的 `--app=` 啟動參數做出接近原生桌面 App 的體驗，完全不需要打包 Electron。後續也補上 PWA manifest，透過 PWA Builder 打包成 MSIX，正式以 AlbertBiahal 名義上架 Microsoft Store。

這支影片記錄了從 v1.0 到 v1.3.0 的版本演進，也是一次「功能先做對、部署流程後補上」的真實工程過程。

🔗 https://www.youtube.com/watch?v=JzPmid-098M

## Facebook（較口語，適合帶個人心得）

這個加班計算機其實是被公司那套很機車的規則逼出來的（午休要扣、晚餐後才開始算、進位方式還要看心情），乾脆寫一個工具把規則全部設定好，之後輸入打卡時間就自動算完，不用每次都重新想一遍。順手做成單一 HTML 檔案，離線也能用，還做了防連點保護。這次也第一次把工具正式上架到 Microsoft Store，整個從寫程式到上架的過程都錄下來了。

🔗 https://www.youtube.com/watch?v=JzPmid-098M
